## Why this layout

- `iac/`, `ansible/`, `docker/`, `k8s/`, `app/` and `monitoring/` are the directories the brief requires.
- `scripts/` holds the helpers so the Makefile stays short and every step can be rerun.
- `docs/` keeps long-form reasoning out of the README, so the README stays a guide for the examiner.
- `.private/` sits inside the tree so relative paths work, but it is gitignored and the secret scan refuses any commit that contains its values.

Terraform state (`iac/terraform.tfstate`) and plans (`iac/tfplan`) contain the VM password and are gitignored.
