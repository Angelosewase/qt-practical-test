## 6. Devops password step (Ansible vm_access, no_log)
Password source: VM_PASSWORD in .private/secrets.env, passed through the environment by `make ansible-run`.
The value is never printed or stored in a tracked file.
- Verification method: `unix_chkpwd` (the PAM helper that sshd and su use). A correct password returns 0 and a wrong one returns 7. Tested on c3-docker-host before it was used in the role.
